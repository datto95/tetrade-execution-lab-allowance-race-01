# Roteiro de Evolucao - allowance-race-01

Objetivo:
Garantir que o laboratorio esteja pronto para uso didatico e revisao tecnica.

Entregas:
- CI no GitHub executando build, testes e validacao de evidencia.
- README com comandos reproduciveis.

## Fase 2 - Fortalecimento

Objetivo:
Ampliar a robustez do lab com mais comportamento validado.

Entregas:
- Testes adicionais cobrindo multiplos spenders concorrentes.
- Fuzz para variacao de limites e ordens de gasto.
- Relatorio de gas para comparar aprovacao vulneravel e segura.

## Fase 3 - Pacote didatico

Objetivo:
Tornar o lab pronto para treinamento interno ou externo.

Entregas:
- Guia passo a passo para aluno.
- Guia para instrutor.
- Checklist de auditoria rapida para fluxos de approve/spend.
